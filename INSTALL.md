# Install

[Português](INSTALL.pt-BR.md)

The extension is **not in the Chrome Web Store or Firefox Add-ons yet**. For now, it can only be installed in developer mode.

Download the files from the [latest release](https://github.com/oozu3/YT-7TV-Client/releases/latest).

## Chrome, Edge, Brave, Opera, Vivaldi, Helium

1. Download `yt-7tv-client-<version>-chromium.zip` and unzip it into a folder you won't delete.
2. Open `chrome://extensions` (`edge://extensions` on Edge).
3. Turn on **Developer mode**.
4. Click **Load unpacked** and pick the folder.

To update, unzip the new version over the same folder and click the reload button on the extension's card.

## Firefox, Zen, Floorp, LibreWolf, Waterfox

1. Download `yt-7tv-client-<version>-firefox.zip`.
2. Open `about:debugging#/runtime/this-firefox`.
3. Click **Load Temporary Add-on…** and pick the zip.

Firefox removes it when the browser closes, so repeat these steps each time. It will stay installed once it's on Firefox Add-ons.
